统一菜单插件（v1.0.0）

菜单模式

文字链接模式（text_link）已移除。全局模式仅两种：文字模式（text）与图片模式（image）。

文字模式下菜单项渲染为 「功能名↗」蓝色字体、不带按钮边框，点击行为与按钮一致；无面板域名或 markdown 权限时自动降级为「（发送「功能名」）」纯文本。

切换方式：群里发 切换全局模式（需超管）。

多机器人隔离与去重

每个机器人（AppID）独立维护已启用模块（setModules）；默认全部启用，配置后仅回复本机器人已开启的菜单与功能。同一消息 5 秒去重，避免 Webhook 与 WebSocket 重复回复。
