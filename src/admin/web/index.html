NapCat OneBot 连接

QQ 开放平台只返回脱敏 OpenID，不提供真实 QQ 号。三种方式获取真实 QQ 号：
① NapCat 同步（推荐，全量自动）：在可扫码登录 QQ 的机器上运行 NapCatQQ，配好 HTTP 服务器后填下面地址，测试连接后点"一键同步"。
② 手动映射：我的机器人 → 群管 → 逐成员填 QQ 号。
③ QQ 一键登录：成员/管理员扫码（可截图远程扫码），回跳后输入 QQ 号即自动绑定真实 QQ 号。下面「一键登录」绑当前登录账号，成员行「扫码绑定」生成该成员专属绑定链接（可发给成员本人扫码）。
开启后才会拉取 NapCat 群列表/同步成员；关闭则不连接 NapCat（概览不再报错）
