📄 页面管理

🧱 页面区块

从上到下即卡片显示顺序。按住区块标题行「≡」拖动可调位置（桌面鼠标按住拖 / 手机长按拖），也可用 ↑↓ 按钮；每个区块上、下都有「＋」（下拉选择类型后插入新板块）；「⇆ 左右并排组」把多个子块排在同一行；每个区块都可选 靠左/居中/靠右 对齐；链接/菜单项/信息项每行左右都有「＋」可插入新项。
