游戏说明

  1. 开始后每位玩家依次查看自己的身份牌：多数人拿到平民词，卧底拿到卧底词（含义相近但有区别），10 人以上可能有人拿到白板。
  2. 每人轮流用一句话描述自己拿到的词（不可以说出词语本身，要努力不被卧底发现）。
  3. 描述完成后大家投票，票数最多者出局；若出局者就是卧底，平民获胜，否则继续下一轮。
  4. 卧底要伪装成平民活到最后；白板玩家要凭描述猜出平民词。
