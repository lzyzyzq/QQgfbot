# QQ Bot 平台 4.2.1 部署文档

> 适用版本：4.2.1（菜单三模式 + 图片菜单 + 唱歌点歌 + PHP 标识）
> 发布日期：2026-08-20

## 一、版本概览

4.2.1 的核心变化是**菜单模式重构**与**新增点歌功能**：

| 功能 | 说明 |
|------|------|
| 菜单三模式 | `文字` / `文字链接`（默认）/ `图片` 三种全局菜单形态，群内发送「切换全局模式」即可切换 |
| 图片菜单 | 深色卡片式菜单图，带发送者头像、昵称、QQ 号，底部 PHP 标识 |
| 唱歌点歌 | 群内发送「唱歌 歌名」返回 QQ音乐/网易云/酷狗/酷我 4 平台点歌链接卡片 |
| 面板 PHP 标签 | 插件管理列表新增「类型」列，显示 PHP·目录 / PHP |
| 消息 PHP 标识 | 菜单消息底部附 PHP·QQ机器人平台 标识 |
| 移除按钮模式 | 原 button（内联键盘）模式取消，遗留按钮调用已全部清理或受模式保护 |

### 依赖的服务端新 API

图片菜单依赖服务端新增 `sendMenuCard` 能力（`renderMenuCard` 渲染 + 分片上传），**必须同步升级 `dist/`**，否则图片模式无法工作。

## 二、包清单

| 文件 | 内容 | 大小 |
|------|------|------|
| `qq-bot-plugins-4.2.1-all.zip` | 全量插件（44 个文件，含 `唱歌.js`） | ~125 KB |
| `qq-bot-server-4.2.1.zip` | 服务端 `dist/` 编译产物（含 sendMenuCard + 面板 PHP 标签） | ~278 KB |

## 三、部署前准备

### 1. 备份服务器现状

```bash
# 备份插件目录
cp -r /var/www/php/plugins /var/www/php/plugins_backup_420_$(date +%Y%m%d)

# 备份数据库
cp /var/www/php/data/bot.db /var/www/php/data/bot.db.bak_420_$(date +%Y%m%d)
```

### 2. 确认服务器环境

```bash
# 确认机器人进程名（本机为 qqbot）
pm2 list

# 确认监听端口（本机 3100，nginx 反代 6655）
pm2 info qqbot
```

### 3. 确认面板对外地址已配置

文字链接模式需要 `panel.host` 可被 QQ 客户端访问，且 QQ 开放平台已添加对应网页跳转域名。检查：

```bash
# 查看当前 panel.host
node -e "var db=require('/var/www/php/node_modules/better-sqlite3')('/var/www/php/data/bot.db');var r=db.prepare(\"SELECT value FROM config WHERE key='panel.host'\").get();console.log(r&&r.value||'(未设置)')"
```

若为空，在面板「系统设置」中配置面板对外地址（如 `https://armbian.tailaa2e36.ts.net:6655` 或反代后的域名）。

## 四、部署步骤

### 第 1 步：上传两个 zip 到服务器

使用 scp/sftp 上传 `qq-bot-plugins-4.2.1-all.zip` 与 `qq-bot-server-4.2.1.zip` 到 `/var/www/php/`（或任意临时目录）。

### 第 2 步：替换全部插件（全新上传）

```bash
# 进入项目目录
cd /var/www/php

# 清空旧插件（备份已在第三节完成）
rm -rf plugins/*
mkdir -p plugins

# 解压全量插件包
unzip -o qq-bot-plugins-4.2.1-all.zip

# 确认目录结构正确（必须有 plugins/qq-bot-plugins/ 子目录）
ls plugins/
```

### 第 3 步：升级服务端 dist

```bash
# 解压 dist 覆盖
unzip -o qq-bot-server-4.2.1.zip

# 确认 sendMenuCard 已包含
grep -c "sendMenuCard" dist/core/bot.js
# 输出 >= 1 即为正常
```

### 第 4 步：重启机器人进程

```bash
pm2 restart qqbot
pm2 logs qqbot --lines 30
```

确认日志无红色报错，出现「插件已启用」类日志即成功。

### 第 5 步：清理发布包（可选）

```bash
rm -f /var/www/php/qq-bot-plugins-4.2.1-all.zip /var/www/php/qq-bot-server-4.2.1.zip
```

| `唱歌.js` | 点歌功能（4.2.1 新增） |
| `按钮菜单.js` | 快捷菜单（已改三模式） |
| `词典回复.js` | 词典回复（已改三模式） |
| `群管理工具.js`、`群信息.js`、`频道管理.js` | 群/频道管理 |
| `授权系统.js`、`签到系统.js`、`定时推送.js` | 授权/签到/定时 |

| `DIC管理.js`、`关键词回复.js`、`问候插件.js`、`Test Plugin.js` | 其它插件 |

### plugins/qq-bot-plugins/ 子目录（zip 套装，17 个文件）

| 文件 | 说明 |
|------|------|
| `plugin.json`、`index.js`（主路由） | 套装入口 |
| `auth.js`、`checkin.js`、`dic.js`、`dictionary.js`、`greeting.js`、`keywords.js` | 授权/签到/DIC/词典/问候/关键词 |
| `entertainment.js`、`utility.js`、`systemtools.js`、`systemsettings.js`、`switches.js`、`groupadmin.js`、`schedule.js`、`scheduler.js`、`permissions.js` | 娱乐/实用/系统工具/系统设置/开关/群管/定时/权限 |

### dist/ 服务端

`qq-bot-server-4.2.1.zip` 解压后覆盖同目录结构（`dist/` 下的 `core/`、`plugin/`、`admin/` 等目录）。验证命令：

```bash
grep -c "sendMenuCard" dist/core/bot.js
# 输出 1 或更大即为已包含（图片模式依赖）
```

## 六、部署后验证清单

### 面板侧

1. 浏览器打开管理面板（`http://服务器IP:6655`），登录正常
2. 进入「插件管理」，表格出现「类型」列，目录型插件显示 `PHP·目录`、单文件插件显示 `PHP` 标签
3. 插件列表显示 `唱歌` 插件（id：`sing`），状态为启用

### 机器人侧（群内验证）

**文字链接模式形态说明**：菜单项显示为**蓝色可点击文字**（`1. [📋 主菜单]` 样式），点击文字即触发对应指令并由机器人回复到群——是"可点击的文字按钮"，纯文字按钮模式。这也是 4.2.1 的默认模式，无需任何配置即可验证（若 `panel.host` 已配置，点击会跳转落地页自动触发；若未配置，蓝字链接退化为纯文本）。

| 测试项 | 操作 | 预期 |
|--------|------|------|
| 主菜单 | 发送「菜单」 | 收到主菜单（默认文字链接模式，编号 + 蓝字链接 + PHP 尾注） |
| 切换图片模式 | 发送「切换全局模式 图片」 | 回复图片菜单：深色卡片、带头像昵称 QQ 号、16 项菜单、底部 PHP 徽标 |
| 切换文字模式 | 发送「切换全局模式 文字」 | 收到纯文字菜单 |
| 切回链接模式 | 发送「切换全局模式 文字链接」 | 收到蓝字链接菜单 |
| 唱歌 | 发送「唱歌 稻香」 | 返回 4 平台点歌链接卡片（QQ音乐/网易云/酷狗/酷我） |
| 子菜单 | 点击链接「娱乐功能」 | 娱乐子菜单同样按当前模式渲染 |
| 欢迎消息 | 让新成员入群 | 欢迎语 + 三模式「查看主菜单」 |

> 注意：`切换全局模式` 命令在不同群独立生效，各群可分别设置。若发送的菜单项在群里显示为普通文本而非蓝字链接，说明 `panel.host` 未配置或 QQ 开放平台未添加跳转域名。

## 七、回滚方案

如遇严重问题，恢复旧版本：

```bash
cd /var/www/php

# 恢复插件
rm -rf plugins
mv plugins_backup_420_YYYYMMDD plugins

# 恢复 dist（需先备份旧 dist，若无则用 git 或重新构建源码）
# 重启
pm2 restart qqbot
```

## 八、常见问题（FAQ）

### 1. 图片菜单发送失败 / 群内不显示图片
- 确认服务端已升级（`grep -c sendMenuCard dist/core/bot.js` 返回 ≥1）
- 确认机器人的图片上传 API 权限正常（QQ 开放平台「富媒体上传」能力）
- 查看日志中是否出现 401，token 应自动刷新重试

### 2. 文字链接模式不生效（菜单显示为纯文本）
- 检查 `panel.host` 是否配置为 QQ 客户端可访问的地址
- 检查 QQ 开放平台是否已将该域名加入「网页可跳转域名」

### 3. 全局模式切换命令无效
- 确认消息为「切换全局模式 图片/文字/文字链接」完整格式
- 三模式关键字：`图片` `文字` `文字链接`（不支持旧的「按钮」关键字）

### 4. 唱歌无反应
- 确认「唱歌」「点歌」后跟歌名，如「唱歌 晴天」
- 确认 `唱歌.js` 插件已启用且在插件列表可见

### 5. 旧按钮菜单仍出现
- 4.2.1 已移除 button 模式，`按钮菜单.js` 改走三模式发送
- 若机器人重启后仍出现键盘按钮，确认 `dist/` 与插件包都已替换为 4.2.1
