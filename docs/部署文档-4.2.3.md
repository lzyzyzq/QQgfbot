# QQ Bot 平台 4.2.3 部署文档

> 适用版本：4.2.3（反馈闭环 + 群信息按群同步 + 定时任务端口修复 + 文字游戏）
> 发布日期：2026-08-20

## 一、版本概览

4.2.3 的核心变化是**反馈闭环打通**、**用户管理按群同步群信息**与**定时任务端口修复**：

| 功能 | 说明 |
|------|------|
| 反馈闭环 | 面板反馈页「回复」按钮 → 机器人私聊回复提交者；群内超级主人「反馈列表」/「回复反馈 ID 内容」；操作成功/失败均有明确提示 |
| 主菜单「📩 反馈」 | 主菜单新增反馈入口（17 项），发送「反馈 内容」提交 |
| @机器人触发修复 | 菜单文本按钮点击带的 `@昵称` 前缀统一清洗，@机器人 与直接发菜单名均触发 |
| 定时任务端口修复 | `process.env.PORT` 与服务真实监听端口同步，修复面板改端口后定时任务/报时/反馈本地 API 全失败 |
| 用户管理按群同步 | 面板用户管理/成员同步页按群展示群头像/群号/群OpenID/群名，支持修改/删除/重新获取；webhook 与 NapCat 自动绑定真实群号 |
| 超级主人群管理 | 「群列表」「修改群名」「修改群号」「获取群信息」命令 |
| 文字游戏 | `games/谁是卧底/` 网页游戏（带图、内置 40 组词库、4-12 人发牌/投票/揭晓） |

### 依赖的服务端新 API

- `GET /api/bot/feedbacks`、`POST /api/bot/feedback/reply`（群内反馈列表/回复）
- `GET /api/bot/groups`、`PUT /api/bot/groups/:id`（群列表/改群名/改群号，isLocal）
- `GET/PUT/DELETE /api/system/groups`、`GET /api/system/user-groups`（面板用户管理）
- `feedbacks` 表 `reply/replied_at` 列、`groups` 表 `group_number/avatar/bot_id` 列（启动自动迁移）
- **必须同步升级 `dist/` 与 `src/admin/web/index.html`**（server zip 已含，部署后直接生效）

## 三、部署前准备

### 1. 备份服务器现状

```bash
# 备份插件目录
cp -r /var/www/php/plugins /var/www/php/plugins_backup_423_$(date +%Y%m%d)

# 备份数据库（新增了 feedbacks.reply、groups.group_number 等列，自动迁移前先备份）
cp /var/www/php/data/bot.db /var/www/php/data/bot.db.bak_423_$(date +%Y%m%d)
```

### 2. 确认服务器环境

```bash
# 确认机器人进程名（本机为 qqbot）
pm2 list

# 确认监听端口（本机 3100，nginx 反代 6655）
pm2 info qqbot
```

> 4.2.3 已自动同步 `process.env.PORT`，即使面板把服务端口改成 3100，插件内本地 API 调用也会走 3100，无需手工配置。

## 四、部署步骤

### 第 1 步：上传两个 zip 到服务器

使用 scp/sftp 上传 `qq-bot-plugins-4.2.3-all.zip` 与 `qq-bot-server-4.2.3.zip` 到 `/var/www/php/`。

### 第 2 步：替换全部插件（全新上传）

```bash
# 进入项目目录
cd /var/www/php

# 清空旧插件（备份已在第三节完成）
rm -rf plugins/*
mkdir -p plugins

# 解压全量插件包
unzip -o qq-bot-plugins-4.2.3-all.zip

# 确认目录结构正确（必须有 plugins/qq-bot-plugins/ 子目录）
ls plugins/
```

### 第 3 步：升级服务端 dist

```bash
# 解压 dist + 面板 index.html + games 覆盖
unzip -o qq-bot-server-4.2.3.zip

# 确认定时任务端口同步代码已包含
grep -c "process.env.PORT = String(PORT)" dist/server.js
# 输出 >= 1 即为正常
```

### 第 4 步：重启机器人进程

```bash
pm2 restart qqbot
pm2 logs qqbot --lines 30
```

确认日志无红色报错，出现「插件已启用」类日志即成功。数据库自动迁移会在启动时执行（新增列）。

### 第 5 步：清理发布包（可选）

```bash
rm -f /var/www/php/qq-bot-plugins-4.2.3-all.zip /var/www/php/qq-bot-server-4.2.3.zip
```

## 七、回滚方案

如遇严重问题，恢复旧版本：

```bash
cd /var/www/php

# 恢复插件
rm -rf plugins
mv plugins_backup_423_YYYYMMDD plugins

# 恢复 dist（需先备份旧 dist，若无则用 git 或重新构建源码）
pm2 restart qqbot
```

数据库自动迁移仅新增列（feedbacks.reply/replied_at、groups.group_number/avatar/bot_id），不破坏旧数据；回滚旧版本代码时新列保留，不影响运行。

## 八、常见问题（FAQ）

### 1. 反馈回复提示「机器人未初始化」或「发送失败」
- 确认服务端已升级且机器人正常登录（面板机器人状态在线）
- 反馈提交者需有 OpenID（群内/私聊发过消息自动收录），无 OpenID 的反馈无法私聊回复

### 2. 修改群号后群头像不显示
- 群号必须是真实数字群号（6-15 位），修改后自动生成 `p.qlogo.cn/gh/{群号}/{群号}/0` 头像
- 头像由 QQ CDN 提供，加载失败通常是群号有误或 QQ 侧未开放该群头像

### 3. 定时任务还是没执行
- 确认 `grep -c "process.env.PORT = String(PORT)" dist/server.js` 输出 ≥1
- 确认面板「系统设置」中服务端口与 pm2 实际监听一致；重启后观察日志有无 schedule 相关错误

### 4. 群里点菜单带 @ 前缀导致指令不识别
- 4.2.3 已统一清洗 `@昵称`/`<@openid>` 前缀；若仍异常确认插件包已全量替换（plugins 包 + dist 同步升级）

### 5. 文字游戏打不开
- 确认 `unzip -o qq-bot-server-4.2.3.zip` 后存在 `src/admin/web/games/谁是卧底/`；服务端 web 目录为 `src/admin/web`，路径含中文需 URL 编码（浏览器自动处理）
