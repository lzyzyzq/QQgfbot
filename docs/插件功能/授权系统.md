# 授权系统.js 功能说明

> 插件ID：`mod-auth` ｜ 版本：v1.0.0 ｜ 作者：511742399 ｜ 状态：活跃（薄转发层）

## 简介

获取激活码、激活授权码。本插件为薄转发层，无独立业务逻辑；实际生成/激活由 `开关机控制` 的本地后端 API 完成。

## 支持的命令

| 命令 | 功能 |
|------|------|
| 「获取激活码」 | 直接转发 `ctx.engine.callPlugin('开关机控制','handleCommand',data)` |
| 「激活授权码」「激活授权码 <码>」 | 同上，转发到开关机控制 |

## 数据存储
无。

## 外部调用
- `ctx.engine.callPlugin('开关机控制','handleCommand')`
- `ctx.engine.callPlugin('主菜单','sendMessage')`（兜底）

## 权限控制
无（权限在转发目标 `开关机控制` 内校验：生成需超级主人、私聊）。

## 维护提示
- 本插件只是开关机控制激活码命令的入口转发，修改业务逻辑应在开关机控制或后端 `/api/bot/auth-codes` 中调整。
