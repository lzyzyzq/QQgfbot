# 唱歌 插件

点歌功能：输入歌名，返回 QQ音乐 / 网易云 / 酷狗 / 酷我 四个平台的点歌链接卡片。

## 基本信息

| 项 | 值 |
|----|-----|
| 插件 ID | `sing` |
| 版本 | 1.0.0 |
| 类型 | PHP 单文件插件 |

## 触发命令

| 命令 | 示例 |
|------|------|
| `唱歌 歌名` | 唱歌 稻香 |
| `点歌 歌名` | 点歌 晴天 |
| `唱首歌 歌名` | 唱首歌 光年之外 |
| `听歌 歌名` | 听歌 起风了 |
| `我要听 歌名` | 我要听 孤勇者 |
| `听首歌 歌名` | 听首歌 晴天 |
| `点首歌 歌名` | 点首歌 演员 |
| `来一首 歌名` | 来一首 演员 |

## 回复内容

- 无歌名：提示用法「发送 唱歌 歌名」
- 有歌名：返回 markdown 点歌卡片，含四个平台搜索链接：
  - QQ音乐：`https://c.y.qq.com/soso/fcgi-bin/client_search_cp?p=1&w={歌名}`
  - 网易云：`https://music.163.com/#/search/m/?s={歌名}`
  - 酷狗：`https://www.kugou.com/yy/html/search.html#searchType=song&searchKeyWord={歌名}`
  - 酷我：`https://www.kuwo.cn/search/list?key={歌名}`
- markdown 发送失败时兜底为纯文本链接列表

## 入口

- 主菜单新增「唱歌」入口（第 13 项），点击后进入点歌引导
- 群内直接发送命令即可使用

## 依赖

- `ctx.bot.sendMarkdownGroup`（markdown 富媒体消息）
- 无需额外配置
