# 签到系统.js 功能说明

> 插件ID：`mod-checkin` ｜ 版本：v2.1.1 ｜ 作者：511742399 ｜ 状态：活跃（「个人信息」子命令保持静默）

## 简介

每日签到、积分系统、补签、排行榜。

## 支持的命令

| 命令 | 功能 |
|------|------|
| 「签到」 | 每日一次；随机 1-100 分，连签 3/7/30 天分别 +20/+50/+200，5% 概率幸运暴击 x2；记录日期/连签/累计 |
| 「补签」 | 未签到时消耗 30 积分补齐昨日，恢复连签计数 |
| 「个人信息」 | **静默 return**（避免双回复），由 `实用工具.js` v1.2.1 富媒体头像卡统一响应 |
| 「签到排行」「积分排行」 | 基于内存用户表扫描各用户累计积分，输出 TOP10（UID 前 8 位） |

## 功能模块
- 签到积分结算（随机 + 连签奖励 + 暴击）
- 补签
- 积分排行
- 按钮/文字双模式回复

## 数据存储
| Key | 说明 |
|-----|------|
| `checkin_<userId>_date` | 最近签到日期 |
| `checkin_<userId>_streak` | 连签天数 |
| `checkin_<userId>_total` | 累计积分 |
| `ctx._checkinUsers` | 用户 UID 集合（进程内存，重启后排行仅统计内存中已签到用户） |

## 外部调用
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- `ctx.bot.sendGroupMessage`（兜底）

## 权限控制
无。

## 维护提示
- 排行榜依赖内存 `ctx._checkinUsers`，重启后仅统计重启后签到的用户，如需全量排行需改为持久化。
