# 系统设置.js 功能说明

> 插件ID：`mod-sys-settings` ｜ 版本：v1.0.0 ｜ 作者：511742399 ｜ 状态：活跃

## 简介

定时关机、整点提醒、撤回信息、管理频道、群成员管理、发布群公告。

## 支持的命令（均需超级主人）

| 命令 | 功能 |
|------|------|
| 「设置定时关机」「设置定时关机 HH:MM」 | 保存定时关机时间 |
| 「整点提醒」「整点提醒 内容」 | 保存整点提醒文案 |
| 「撤回信息」「撤回信息 消息ID」 | 获取 access_token 后调 QQ 官方 API `DELETE /v2/groups/<groupId>/messages/<msgId>` 撤回机器人消息 |
| 「管理频道」「管理频道 频道ID 内容」 | `ctx.bot.sendMessage` 向频道推送消息 |
| 「管理频道人员」 | 帮助说明 |
| 「管理频道人员 禁言 @用户 分钟」 | 群成员禁言 |
| 「管理频道人员 解禁 @用户」 | 群成员解禁 |
| 「管理频道人员 踢人 @用户」 | 群成员踢出 |
| 「发布群公告」「发布群公告 内容」 | `ctx.bot.setAnnouncement` 发布公告 |

## 数据存储
| Key | 说明 |
|-----|------|
| `shutdown_time` | 定时关机时间 |
| `hourly_tip` | 整点提醒文案 |
| `bot_app_id` / `bot_app_secret` | 读取（撤回消息用） |
| `super_master_id` | 读，判权 |
| `data/bot.db` config 表 | 只读 `bot.app_id`/`bot.app_secret`（better-sqlite3） |

## 外部调用
- `ctx.bot.sendMessage/muteMember/unmuteMember/kickMember/setAnnouncement`
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- HTTPS 调 `bots.qq.com/app/getAppAccessToken` 与 `api.sgroup.qq.com` 撤回接口
- `better-sqlite3` 读 SQLite

## 权限控制
所有命令需超级主人。

## 维护提示
- 撤回消息走 QQ 官方 app token 接口，涉及密钥读取，改动时勿输出明文密钥。
