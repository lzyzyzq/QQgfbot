# 词典回复.js 功能说明

> 插件ID：`builtin-dict` ｜ 版本：v1.0.0 ｜ 作者：系统 ｜ 状态：活跃

## 简介

从 dict 文件读取问答，支持按钮和 Markdown 回复。由 DIC管理 的「开启/关闭dic回复」「写入dic」控制。

## 支持的命令
无固定文本命令。启动时从 `plugins/dict.txt`（或 `ctx.config.dictDir`）按 `关键词|回复内容` 格式加载词典，对任意消息先做精确匹配、再做按 key 长度降序的子串匹配。

## 功能模块
- 词典加载（跳过 `#` 注释与空行）
- 占位符解析：
  - `{{number}}`：随机 1-100 并激活猜数字
  - `{{time}}`：北京时间
  - `{{dice}}`、`{{joke}}`、`{{fortune}}`
- 结构化回复：回复内容为 JSON 对象时按 `type` 分发——`keyboard`（按钮键盘）、`markdown`（Markdown 消息）、`text`（纯文本），支持群/私聊/频道三通道
- 猜数字游戏状态机（`gameState`，猜中/太大/太小）

## 数据存储
- 无 ctx.storage；词典来自文件
- 游戏状态存进程内存（重启丢失）

## 外部调用
- `ctx.bot.sendMessage/sendGroupMessage/sendPrivateMessage/sendKeyboardGroup/sendKeyboardPrivate/sendMarkdownGroup/sendMarkdownPrivate`
- `ctx.config.dictDir`、Node `fs`
- `ctx.eventBus`（message.guild/c2c/group）

## 权限控制
无。

## 维护提示
- 词典文件格式 `关键词|回复内容`，修改后需重载插件（DIC管理「写入dic」会自动重载）。
