# 主菜单.js 功能说明

> 插件ID：`mod-main-menu` ｜ 版本：v4.0.0 ｜ 作者：511742399 ｜ 状态：活跃（「实用功能」入口已静默）

## 简介

主菜单导航插件，负责展示主菜单、子菜单按钮面板，并把各功能命令路由到对应的子插件。

## 支持的命令

### 主菜单/子菜单
- 「娱乐功能」「娱乐」：展示娱乐子菜单按钮
- 「实用功能」「实用」：展示实用工具子菜单（路由到 `实用工具`，实现方见下）
- 「授权功能」「授权」：展示授权子菜单
- 「系统功能」「系统」：展示系统子菜单
- 「设置功能」「设置」：展示设置子菜单
- 「DIC设置」「dic设置」「词典设置」：展示 DIC 子菜单
- 「群管系统」「群管」：展示群管子菜单

### 命令路由（转发到对应插件）
- 娱乐类：`今日运势/掷骰子/猜拳/选择/随机数/今天吃什么/今日人品/仙逆/抽老婆/抽老公/扫雷/敲木鱼/开心农场/去钓鱼/猜数字/笑话` → 路由到 `娱乐中心`
- 实用类：`每日备注/每日打卡/设置昵称/查询天气/个人信息` → 路由到 `实用工具`（v1.2.1 富媒体头像卡，见 [实用工具.md](./实用工具.md)）
- 授权类：`获取激活码/激活授权码` → 路由到 `授权系统`
- 系统工具类：`在线时间/版本/更新日志/查巡` → 路由到 `系统工具`
- 系统设置类：`设置定时关机/整点提醒/撤回信息/管理频道/管理频道人员/发布群公告` → 路由到 `系统设置`
- 定时推送类：`定时推送/每日早报/每日晚报/生日提醒/间隔推送/定时任务列表/定时列表/定时任务` → 路由到 `定时推送`
- DIC类：`开启dic回复/关闭dic回复/写入dic/设置底部广告/模式设置` → 路由到 `DIC管理`
- 群管类：`开启群全禁/关闭群全禁/禁言/解禁/踢人` → 路由到 `群管理工具`
- 签到类：`签到/补签/补签确认/签到排行/积分排行` → 路由到 `签到系统`
- 未匹配命令 → 兜底路由到 `开关机控制`

### 固定文案回复
- 「拉我进群」「赞助」「赞助广告」「作者」「作者QQ」「帮助」

## 功能模块
- 全局按钮/文字双模式发送（读取 `global_mode`）
- 菜单底部广告拼接（读 `footer_ad_<菜单名>`，缺省用内置默认广告 + 招租文案）
- 各子菜单按钮面板生成
- 命令路由分发中枢

## 数据存储
| Key | 说明 |
|-----|------|
| `global_mode` | 全局模式（读） |
| `footer_ad_<菜单名>` | 各子菜单底部广告（读，回退默认广告） |

## 外部调用
- `ctx.engine.callPlugin('娱乐中心'/'实用工具'/'授权系统'/'系统工具'/'系统设置'/'定时推送'/'DIC管理'/'群管理工具'/'签到系统'/'开关机控制', ...)`
- `ctx.bot.sendGroupMessage` / `ctx.bot.sendKeyboardGroup`

## 权限控制
无权限限制，所有命令对任何用户开放。

## 维护提示
- 修改子菜单项时，注意「实用功能」分支已静默，新入口由 qq-bot-plugins 的 `utility.js` 负责，两处不要同时开启，避免重复弹窗。
- 新增子插件时，需同时在此插件增加路由分支与命令表。
