# 实用工具.js 功能说明

> 插件ID：`mod-utils` ｜ 版本：v1.2.1 ｜ 作者：511742399 ｜ 状态：**活跃（个人信息为富媒体头像卡）**

## 简介

每日备注、每日打卡、设置昵称、图片天气、个人信息（头像卡）。

历史上本插件曾整体静默、由 `qq-bot-plugins/utility.js` 统一实现；qq-bot-plugins 包已不再随仓库分发，v1.2.x 起本插件恢复为唯一实现方。

## 支持的命令

| 命令 | 功能 |
|------|------|
| 「每日备注」「每日备注 内容」 | 按用户+日期读写当日备注 |
| 「每日打卡」 | 每日一次，随机 10-59 分，连签 7/30 天有 20/50 加分，累计积分 |
| 「设置昵称」「设置昵称 昵称」 | 保存 1-20 字昵称（本地 storage） |
| 「查询天气 城市」/「天气 城市」 | 图片天气（wttr.in PNG 富媒体上传）；失败自动回退本地增强天气接口 `/api/bot/weather`（7 天预报+预警+空气+紫外线等） |
| 「个人信息」 | **富媒体头像卡**（见下） |

## 「个人信息」实现说明（v1.2.1）

1. 读本地 storage 组装打卡数据：今日是否已打卡、连续天数、累计积分、今日备注。
2. 调 `ctx.engine.getUserProfile(userOpenid, 1)`（本地 DB 聚合，与网页面板/新版菜单同源）取 `qq_number / nickname / avatar / permission / auth_role`。
3. 拼 Markdown：`![头像](__AVATAR__)` 占位 + 群名/昵称/QQ/用户ID/权限/授权 + 打卡/备注。
4. 发送：存在 `ctx.bot.sendGroupMarkdownWithImage` 时调用（头像富媒体图单独发出、占位自动删除）；否则回退 `sendMarkdownGroup` 并剔除占位行。

权限展示优先级：`panel_role`（后台面板角色）→ `auth_role`（激活码角色）→ 普通用户。`签到系统.js` 对「个人信息」保持静默，避免与本书双回复。

## 数据存储
- `note_<userId>_<日期>`
- `checkin_util_<userId>_<日期>`
- `checkin_util_streak_<userId>`
- `checkin_util_total_<userId>`
- `nickname_<userId>`

## 权限控制
无（普通群成员可用）。

## 依赖接口
- `ctx.engine.getUserProfile` / `ctx.engine.getGroupName`（本地）
- `ctx.bot.sendGroupMarkdownWithImage` / `sendMarkdownGroup` / `uploadGroupImage` / `sendGroupImageMessage`
- `/api/bot/weather`（本地天气兜底）

## 维护提示
- 个人信息无头像时占位会替换为「未绑定QQ无法获取」，引导用户先发「绑定QQ」。
