# 实用工具.js 功能说明

> 插件ID：`mod-utils` ｜ 版本：v1.0.0 ｜ 作者：511742399 ｜ 状态：**已静默（整体停用）**

## 简介

每日备注、每日打卡、设置昵称、查询天气、个人信息。

**当前状态说明**：`handleCommand` 开头直接 `return` 整体静默。顶部注释标明全部实用命令已由 `qq-bot-plugins/utility.js` 统一实现（含 QQ/OpenID/头像图片，数据与网页端同源）。旧插件若重复回复会造成群内刷屏，因此整体停用。**请勿再启用本插件**，后续功能维护以 qq-bot-plugins 的 `utility.js` 为准。

## 支持的命令（已静默，均不生效）

| 命令 | 原功能 |
|------|--------|
| 「每日备注」「每日备注 内容」 | 按用户+日期读写当日备注 |
| 「每日打卡」 | 每日一次，随机 10-59 分，连签 7/30 天有 20/50 加分，累计积分 |
| 「设置昵称」「设置昵称 昵称」 | 保存 1-20 字昵称 |
| 「查询天气」「查询天气 城市」 | 调 wttr.in 返回天气/温度/湿度/风力 |
| 「个人信息」 | 旧格式，由 qq-bot-plugins/utility.js 统一走后端 userinfo |

## 数据存储（代码中定义但不可达）
- `note_<userId>_<日期>`
- `checkin_util_<userId>_<日期>`
- `checkin_util_streak_<userId>`
- `checkin_util_total_<userId>`
- `nickname_<userId>`
