# 系统工具.js 功能说明

> 插件ID：`mod-sys-tools` ｜ 版本：v1.0.0 ｜ 作者：511742399 ｜ 状态：活跃

## 简介

在线时间、版本号、更新日志、查巡（敏感词）。数据读取网页后端，与网页端同源。

## 支持的命令

| 命令 | 功能 |
|------|------|
| 「系统功能」「系统工具」 | 系统工具按钮菜单 |
| 「在线时间」 | 调后端 GET `/api/bot/uptime`，回退 `process.uptime()` |
| 「版本」 | 调后端 GET `/api/bot/version`，回退内置平台版本，并列出各插件版本号 |
| 「更新日志」 | 调后端 GET `/api/bot/changelog` 并清洗 Markdown，回退内置更新日志 |
| 「查巡」 | 显示敏感词库说明 |
| 「查巡 添加 词」 | 添加敏感词 |
| 「查巡 删除 词」 | 删除敏感词 |
| 「查巡 列表」 | 列出敏感词 |

## 数据存储
- `bad_words`（JSON 数组）

## 外部调用
- 本地 HTTP `127.0.0.1:3000` 的 `/api/bot/uptime`、`/api/bot/version`、`/api/bot/changelog`
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- `ctx.bot.sendGroupMessage`（兜底）

## 权限控制
**无权限检查**（含「查巡 添加/删除」敏感词操作，任何用户均可执行——注意此点，如需收紧请补权限校验）。
