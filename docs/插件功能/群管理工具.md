# 群管理工具.js 功能说明

> 插件ID：`mod-group-admin` ｜ 版本：v3.0.0 ｜ 作者：511742399 ｜ 状态：活跃

## 简介

开启/关闭群全禁、禁言、解禁、踢人。

## 支持的命令（均需主人）

| 命令 | 功能 |
|------|------|
| 「开启群全禁」 | 写 `group_mute_<groupId>=1`，随后该群非主人消息被拦截并提示 |
| 「关闭群全禁」 | 写 `group_mute_<groupId>=0` |
| 「禁言 @用户 分钟」 | 解析 `@openid`，`ctx.bot.muteMember` 禁言（默认 10 分钟） |
| 「解禁 @用户」 | `ctx.bot.unmuteMember` |
| 「踢人 @用户」 | `ctx.bot.kickMember` |

## 功能模块
- 命令处理
- `onEnable` 注册 `message.group` 监听实现全员禁言拦截（非主人消息不转发，仅回复提示）

## 数据存储
| Key | 说明 |
|-----|------|
| `group_mute_<groupId>` | 群全禁开关（`1`/`0`） |
| `super_master_id` / `mini_masters` | 读，判权 |

## 外部调用
- `ctx.bot.muteMember/unmuteMember/kickMember/sendGroupMessage`
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- `ctx.eventBus`

## 权限控制
全禁/禁言/解禁/踢人均需主人（超级主人或已激活小主人）。

## 维护提示
- 群全禁拦截在 `onEnable` 的事件监听中实现，若需调整拦截逻辑（如放行白名单）在此处修改。
