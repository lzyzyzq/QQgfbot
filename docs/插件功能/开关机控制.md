# 开关机控制.js 功能说明

> 插件ID：`builtin-power` ｜ 版本：v4.0.0 ｜ 作者：511742399 ｜ 状态：活跃（承担权限与消息路由中枢）

## 简介

核心控制插件：开关机、三级权限管理、整点报时、欢迎/退群、全局模式、激活码生成与激活、事件路由中枢。

## 支持的命令

### 开关机
- 「开机」「关机」：**任何人可用**；`enableAllExcept/disableAllExcept` 启停除自身外的全部插件（代码中明确移除了权限检查）

### 权限管理
- 「设置主人」：首次设置超级主人（已存在则拒绝），写入 `super_master_id`（含 openid/qqId/时间戳）
- 「主人列表」：展示超级主人/小主人/会员及其激活状态

### 报时与模式
- 「整点报时」「整点报时 开/关」：主人；查询/切换整点报时
- 「切换全局模式」「全局模式 [按钮|文字]」：主人；切换/翻转全局模式

### 激活码（走后端，与面板同源）
- 「生成激活码 [超级主人|小主人|会员] [分钟]」：超级主人，**仅私聊**；调本地后端 `POST /api/bot/auth-codes`
- 「激活授权码 [码]」「激活码 [码]」：群聊公开使用；调本地后端 `POST /api/bot/auth-codes/verify` 验证并标记 used，按角色写入 super_master_id / mini_masters / members

### 菜单与文案
- 「主菜单」「菜单」：发按钮版或文字版主菜单
- 「系统菜单」：系统控制按钮面板
- 「帮助」「帮助文档」「help」「赞助」「赞助广告」「赞助支持」「拉我进群」「邀请入群」「拉我入群」「作者」「联系作者」「作者信息」：固定文案回复

### 事件路由
- 子菜单关键词（娱乐功能/实用功能/授权功能/系统功能/设置功能/DIC设置/群管系统）、定时推送命令、授权码命令 → 分别路由到对应插件

## 功能模块
- 核心开关机
- 三级权限体系（super/master/member）
- 激活码生成与激活
- 整点报时定时器（按北京时间整点、精确到分钟对齐）
- 新成员欢迎与退群提示
- 全局按钮/文字模式
- 事件路由中枢

## 数据存储
| Key | 说明 |
|-----|------|
| `super_master_id` | 超级主人（JSON `{id, qqId, added_at}`） |
| `mini_masters` | 小主人数组（含 activated） |
| `members` | 会员数组（含 activated） |
| `global_mode` | `button`/`text` |
| `chime_enabled` | 整点报时开关 |
| `active_groups` | 报时目标群（24h 活跃过滤） |

## 外部调用
- `ctx.engine.enableAllExcept/disableAllExcept/isAllOthersEnabled/callPlugin`
- `ctx.bot.sendGroupMessage/sendKeyboardGroup/sendPrivateMessage/sendMessage`
- 本地 HTTP `127.0.0.1:3000` 的 `/api/bot/auth-codes` 与 `/api/bot/auth-codes/verify`
- `ctx.eventBus`（message.guild/c2c/group、group.member.add/remove）
- `setTimeout` 报时调度

## 权限控制
- 开机/关机：任何人
- 设置主人：仅首次
- 整点报时/全局模式：主人
- 生成激活码：超级主人且仅私聊
- 激活授权码：公开
