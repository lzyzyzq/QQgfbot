# 插件功能说明索引

> 更新日期：2026-08-20

## 插件体系总览

机器人采用「旧版独立插件 + 新版插件套装」两套体系并存：

- **旧版独立插件**：位于 `plugins/` 根目录的 16 个 `.js` 文件，每个插件独立启用，DB 中 `id` 形如 `file-<名字>`。
- **新版插件套装 qq-bot-plugins**：位于 `plugins/qq-bot-plugins/` 目录（DB 中 `type=zip`，`id=6a562134-...`），主入口 `index.js` 只做三层路由分发（主菜单 → 子菜单 → 子子菜单），内置权限体系、用户管理、定时调度。

**当前去重原则**：两套体系通过 EventBus 广播同时监听消息事件。为避免重复回复/旧格式覆盖，以下命令已由新版套装统一接管，旧版对应实现已静默禁用：

- `实用工具.js`：整体静默（每日备注/每日打卡/设置昵称/查询天气/个人信息 由 `qq-bot-plugins/utility.js` 统一实现，数据与网页端同源）
- `主菜单.js`：「实用功能/实用」菜单入口静默，由 `qq-bot-plugins/utility.js` 弹出新菜单
- `签到系统.js`：「个人信息」子命令静默，由 `qq-bot-plugins/utility.js` 统一处理

## 新版插件套装 qq-bot-plugins（1 个 zip 插件）

| 说明 | 文档 |
|------|------|
| 套装全部功能（主路由 + 15 个子模块） | [qq-bot-plugins.md](./qq-bot-plugins.md) |

套装子模块清单：index（主路由/权限/用户管理）、auth（授权）、checkin（签到）、dic（DIC管理）、dictionary（词典回复）、entertainment（娱乐）、greeting（问候）、groupadmin（群管）、keywords（关键词）、permissions（权限共享）、schedule（定时推送命令层）、scheduler（定时调度执行层）、switches（功能开关）、systemsettings（系统设置）、systemtools（系统工具）、utility（实用工具）。

## 数据存储两轨说明

- **插件级（ctx.storage）**：`super_master_id`、`mini_masters`、`members`、签到、备注、昵称、词典、敏感词、底部广告、全局模式等。部分 key 重启前为内存态（娱乐游戏、词典游戏状态）。
- **后端级（`127.0.0.1:3000` 的 `/api/bot/*`）**：用户管理 `admin-users`、激活码 `auth-codes`、定时任务 `schedule-tasks`、功能开关 `switches`、活跃群 `groups`、个人信息 `userinfo`、天气 `weather`、系统信息 `uptime/version/changelog` 等，与网页面板同源、重启不丢失。
