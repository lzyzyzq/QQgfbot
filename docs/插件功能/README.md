## 插件体系总览（现状）

机器人插件统一位于 `plugins/` 根目录（js / php / py 单文件），通过 EventBus 广播接收群/私聊消息事件；`主菜单` 是入口菜单，其余插件各自响应命令。`qq-bot-plugins` zip 套装与旧版“整体静默”去重机制已随套装移除而终结，相关说明仅作归档：[qq-bot-plugins.md](./qq-bot-plugins.md)、[按钮菜单.md](./按钮菜单.md)、[主菜单.md](./主菜单.md)。

**当前「个人信息」去重约定**：

- `实用工具.js` v1.2.1（`mod-utils`）：**唯一响应方**，输出富媒体头像卡（`ctx.engine.getUserProfile` + `sendGroupMarkdownWithImage`），数据与网页面板同源。
- `签到系统.js`（`mod-checkin`）：「个人信息」子命令静默 `return`，避免与实用工具双回复；`签到系统` 卡片中若出现个人信息按钮请改指“实用功能”。
- `主菜单`：实用类入口（每日备注/打卡/设置昵称/天气/个人信息）路由到 `实用工具`。

## 数据存储两轨说明

- **插件级（ctx.storage）**：super_master_id、mini_masters、members、签到、备注、昵称、词典、敏感词、底部广告、全局模式等。部分 key 重启前为内存态。
- **后端级（`127.0.0.1:3000` 的 `/api/bot/*`）**：用户管理 `admin-users`、激活码 `auth-codes`、定时任务 `schedule-tasks`、功能开关 `switches`、活跃群 `groups`、个人信息 `userinfo`、天气 `weather`、系统信息 `uptime/version/changelog` 等，与网页面板同源、重启不丢失。
