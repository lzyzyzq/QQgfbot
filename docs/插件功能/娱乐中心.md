# 娱乐中心.js 功能说明

> 插件ID：`mod-entertainment` ｜ 版本：v3.0.0 ｜ 作者：511742399 ｜ 状态：活跃

## 简介

娱乐功能集合：今日运势、掷骰子、猜拳、选择、随机数、今天吃什么、今日人品、仙逆、抽CP、扫雷、敲木鱼、开心农场、去钓鱼、猜数字、笑话。

## 支持的命令

| 命令 | 功能 |
|------|------|
| 「今日运势」「运势」 | 随机返回 7 种运势文案之一 |
| 「掷骰子」「掷骰子 N d M」 | 掷骰子，N 上限 10、M 上限 100，输出点数与合计 |
| 「猜拳 石头/剪刀/布」 | 与机器人猜拳判胜负 |
| 「选择 选项1 选项2 …」 | 随机选一 |
| 「随机数 最小 最大」 | 生成区间随机数（自动纠正大小） |
| 「今天吃什么」 | 随机推荐 15 种食物之一 |
| 「今日人品」 | 随机 0-100 人品分与评级 |
| 「仙逆」 | 修仙养成：凡人→真仙共 10 境界，随机加经验/灵石，经验满升级 |
| 「抽老婆」「抽老公」 | 随机分配今日 CP 昵称 |
| 「扫雷」 | 初始化 8x8/10 雷多人扫雷；「扫雷 行,列」翻开格子，递归展开、踩雷判负、翻全判胜 |
| 「敲木鱼」 | 随机加 1-3 功德，累计功德与敲击次数 |
| 「开心农场」 | 随机种下作物，10 秒后收获随机金币 |
| 「去钓鱼」 | 随机钓获并累计金币 |
| 「笑话」「讲笑话」 | 随机返回笑话 |
| 「猜数字」 | 开局生成 1-100 目标；「猜数字 数字」猜数并给大小提示，猜中可再来一局 |

## 数据存储
**无持久化 storage**。全部游戏状态存进程内存：`ctx._xianni`（修仙）、`ctx._minesweeper`（扫雷，按群）、`ctx._muyu`（木鱼）、`ctx._farm`（农场）、`ctx._fish`（钓鱼）、`ctx._guess`（猜数字，按用户）。**重启后游戏进度清零。**

## 外部调用
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- `ctx.bot.sendGroupMessage`（兜底）

## 权限控制
无。

## 维护提示
- 游戏状态均为内存态，若需跨重启保留，需改用 `ctx.storage`。
- 修改游戏参数（雷数、境界、食物列表等）在文件内相应数组/常量中调整。
