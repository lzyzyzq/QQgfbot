# 定时推送.js 功能说明

> 插件ID：`mod-scheduler` ｜ 版本：v1.0.0 ｜ 作者：511742399 ｜ 状态：活跃

## 简介

每日定时消息、生日提醒、间隔推送。

## 支持的命令（均需主人权限）

| 命令 | 功能 |
|------|------|
| 「每日早报」 | 显示当前群早报 |
| 「每日早报 HH:MM 内容」 | 设置早报（覆盖同群旧任务） |
| 「每日晚报」「每日晚报 HH:MM 内容」 | 同上，晚间推送 |
| 「生日提醒」 | 显示生日列表与用法 |
| 「生日提醒 添加 名字 MM-DD」 | 添加生日 |
| 「生日提醒 删除 序号」 | 删除生日 |
| 「生日提醒 列表」 | 列出生日 |
| 「间隔推送」 | 显示用法 |
| 「间隔推送 开启/关闭」 | 开关本群间隔推送 |
| 「间隔推送 设置 分钟 内容」 | 设置间隔任务（间隔下限 5 分钟） |
| 「定时任务列表」「定时列表」 | 列出本群早报/晚报/间隔任务及生日提醒 |
| 「定时任务 删除 序号」 | 按本群序号删除定时任务 |

## 功能模块
- 命令处理：早报/晚报/生日/间隔推送任务的增删查
- `onEnable` 启动 30 秒轮询定时器：按北京时间 `HH:MM` 触发早报/晚报；按 `interval_push_enabled_<groupId>` 与内存 `lastIntervalFire` 触发间隔推送；每日 09:00 群发当天生日祝福

## 数据存储
| Key | 说明 |
|-----|------|
| `scheduled_tasks` | JSON 数组（type/groupId/time/intervalMin/content/createdBy） |
| `birthdays` | JSON 数组（name/date/addedBy） |
| `interval_push_enabled_<groupId>` | 间隔推送开关 |
| `morning_msg_<groupId>` / `evening_msg_<groupId>` | 展示当前内容（写入实际走 scheduled_tasks） |
| `active_groups` | 活跃群过滤（24h 内有消息的群） |

## 外部调用
- `ctx.engine.callPlugin('主菜单','sendMessage')`
- `ctx.bot.sendGroupMessage`（轮询推送与兜底）
- `setInterval/clearInterval`

## 权限控制
全部命令需主人（超级主人或已激活小主人）。

## 维护提示
- 本插件任务存插件 storage；新版 qq-bot-plugins 的 schedule/scheduler 走后端 config 表。两套定时体系并存，修改时注意区分。
