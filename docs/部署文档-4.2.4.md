# QQ Bot 平台 4.2.4 部署文档

> 适用版本：4.2.4（插件回复 PHP 模板 + 群内绑定QQ自动填充个人信息）
> 发布日期：2026-08-20
> 前置：需先部署 4.2.3（反馈闭环 + 群信息按群同步 + 定时任务端口修复），4.2.4 为增量升级。

## 一、版本概览

| 功能 | 说明 |
|------|------|
| 插件回复 PHP 模板 | 插件回复用 `<php? 内容 php>` 包裹时，系统自动提取内容 + 尾部信息（`bot.footer_text`，是什么就是什么，默认 `PHP · QQ机器人平台`）+ 底部广告（`bot.footer_ads` 随机一行）；无标记消息不追加 |
| 尾部信息可配置 | 面板「系统设置」新增「底部尾部信息」输入框 |
| 群内绑定 QQ | 群里回复「绑定QQ QQ号」即绑定，写入用户列表（user_mappings）、所在群与群信息（groups/group_members），自动获取头像（q1.qlogo.cn）与昵称，回复展示 QQ/昵称/头像/所在群 |
| 个人信息留空修复 | 绑定后菜单头部与「个人信息」命令即时显示头像/QQ/昵称；未绑定显示「未绑定」+ 首字母占位 |
| 菜单统一渲染 | 主菜单/子菜单/子子菜单菜单项为蓝色文字+`↗` 链接（每行 2 个），普通项点击后经 `/click` 指令触发页由机器人自动在群里回复对应子菜单；仅「登录」「赞助」等 `url:`/`panel:` 项直达链接。依赖面板「系统设置-面板域名 panel.host」配置（你的服务器公网域名/IP），未配置时普通项与 `panel:` 项退化为纯文字、提示自动切换为「输入菜单名即可触发」。附「文字按钮测试」插件（发送「文字按钮测试」查看，配合「模式设置」切换文字/文字链接/图片对比效果） |
| NapCat 插件兼容层 | 支持上传 NapCatQQ 格式插件（导出 `plugin_init`/`plugin_onmessage`/`plugin_onevent`/`plugin_config_ui`，如 MKbot），面板显示/启停/设置界面/webui 全支持；消息事件按 OneBot v11 语义转换（user_id=QQ号、group_id=数字群号），动作映射到本平台 API。详见 `docs/NapCat插件兼容层.md` |

### 依赖的服务端新 API / 模块

- 新增 `src/core/php-footer.ts`（`applyPhpTemplate`），挂到 `BotCore.sendGroupMessage/sendPrivateMessage` 统一出口
- `/api/bot/bind-qq` 增强：接收 `group_id/bot_id/nickname`，绑定群信息 + 成员归属，返回头像/群信息
- config 新增 `bot.footer_text`
- 新增 `src/core/php-plugin.ts`（PHP 插件执行器）：扫描 `plugins/` 下 `.php` 文件并执行（需环境安装 php-cli，未安装自动跳过并日志提示）；图片菜单乱码修复（card.ts 过滤 emoji）
- 新增单文件 `.mjs` 插件引擎：`plugins/*.mjs` 自动发现/注册/启停，支持 `export default { manifest, onEnable }`
- 新增插件设置界面（WebUI）：单文件插件放 `plugins/{插件名}/webui/` 即显示「设置」按钮；ZIP 插件兼容 package.json `webui` 字段；新增 `/api/plugins/:id/config` 配置读写接口
- **必须同步升级 `dist/` 与 `src/admin/web/index.html`**（server zip 已含）

## 三、部署步骤（先确认 4.2.3 已就位）

> 若上次 4.2.3 部署时 `grep dist/server.js` 报 `No such file or directory`，说明命令在错误目录执行或 server 包未解压。请先确认位置：

```bash
# 1. 进入项目目录（关键：不是 root 家目录）
cd /var/www/php
ls -la dist/server.js        # 必须存在，4.2.3 已部署的应有该文件
```

```bash
# 2. 备份
cd /var/www/php
cp -r plugins plugins_backup_424_$(date +%Y%m%d)
cp data/bot.db data/bot.db.bak_424_$(date +%Y%m%d)

# 3. 解压两个新包（zip 内自带 plugins/、dist/、src/ 前缀，不要加 -d）
unzip -o qq-bot-plugins-4.2.4-all.zip
unzip -o qq-bot-server-4.2.4.zip

# 4. 验证关键改动
grep -c "applyPhpTemplate" dist/core/bot.js        # 输出 >= 1
grep -c "process.env.PORT = String(PORT)" dist/server.js  # 输出 >= 1（4.2.3 内容，确认同步升级）

# 5. 重启
pm2 restart qqbot
pm2 logs qqbot --lines 30
```

## 五、FAQ

### 1. `grep: dist/server.js: No such file or directory`
在 `/var/www/php` 目录下执行（相对路径依赖 cwd），且确认 server zip 已解压：`ls dist/server.js`。

### 2. 绑定成功但个人信息仍空
绑定后 `user_mappings` 即时生效；若还显示旧值，重发一次消息即可（无缓存）；确认服务端已升级到 4.2.4（bind-qq 增强版）。

### 3. 回复没有自动加 PHP 尾部信息
只有消息文本包含 `<php? 内容 php>` 标记才会追加；纯文本命令回复不加（避免全部消息带尾注）。
