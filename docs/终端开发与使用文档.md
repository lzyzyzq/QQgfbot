# 终端开发与使用文档

本平台内置 **部署终端**（管理面板页面）与 **群内终端更新** 能力，均以服务器 `/var/www/php` 为部署根目录，通过 `pm2 restart qqbot` 重启机器人。无需再 SSH。

## 1. 面板「部署终端」

### 入口
管理面板侧边栏 → **部署终端**（仅超级主人可用）。

### 交互
- **命令输入框**：输入命令后回车执行，`↑/↓` 切换历史命令。
- **会话目录**：默认 `cwd = /var/www/php`（部署根目录）。
  - `cd /var/www/php`、`cd ..`、`cd ~` 切换目录，会话内持久。
  - 其余命令在会话 cwd 下用 `sh -c` 执行。
- **快捷按钮**：
  - `cd /var/www/php`：回到部署根目录
  - `pm2 状态`：查看机器人进程状态
  - `重启机器人`：`cd /var/www/php && pm2 restart qqbot`

### 后端
`POST /api/system/terminal/exec`（`src/admin/routes/system.ts`），`requireSuperMaster` + 管理 token。超时默认 30s（最大 120s）。

## 2. 常用终端命令

```bash
# 查看机器人进程状态
pm2 status
pm2 logs qqbot --lines 50
pm2 restart qqbot

# 查看部署目录
ls /var/www/php
cd /var/www/php

# 解压更新包
cd /var/www/php && unzip -o patch-4.2.60.zip

# 查看 Node/PHP 版本
node -v && npm -v && php -v
```

## 3. 群内终端更新（群内直接发命令）

在群里直接发送以下命令（**仅超级主人**），机器人自动识别并执行「下载 → 校验 → 解压 → 重启」：

```bash
# 更新补丁包
cd /var/www/php && wget -O patch-4.2.60.zip https://8091-xxxx.monkeycode-ai.online/qqbot-card-editor-patch-4.2.60.zip && unzip -o patch-4.2.60.zip && pm2 restart qqbot

# 更新全量包
cd /var/www/php && wget -O full-4.2.60.zip https://8091-xxxx.monkeycode-ai.online/qqbot-card-editor-4.2.60-full.zip && unzip -o full-4.2.60.zip && pm2 restart qqbot
```

### 识别规则（更新系统插件 `plugins/更新系统.php`）
- 格式固定：`cd <部署根目录> && wget -O <zip名> <URL> && unzip -o <zip名> && pm2 restart qqbot`
- 目录必须等于部署根目录（`/var/www/php`，或环境变量 `PHP_PLUGIN_ROOT_DIR`）；
- `wget` 的 `-O` 文件名与 `unzip` 的文件名必须一致，且以 `.zip` 结尾；
- `pm2 restart` 的目标必须是 `qqbot`；
- URL 必须是 `http://` 或 `https://`；
- 任一不满足即不识别（防命令注入），消息走普通指令流程。

### 执行流程
1. 群内反馈「⏳ 正在下载…」；
2. 下载到 `data/database/更新/<zip名>`；
3. `unzip -t` 校验压缩包完整性；
4. `unzip -o` 解压到部署根目录；
5. 记录更新记录（从 zip 名提取版本号）；
6. 反馈「✅ 更新完成」，3 秒后 `pm2 restart qqbot`。

## 4. 更新系统插件（菜单方式）

发送「更新」/「更新菜单」可调出更新菜单（图片卡片 + 指令按钮）：

| 指令 | 作用 |
|------|------|
| `更新` / `更新菜单` / `返回更新` | 更新菜单（版本对比 + 更新内容 + 按钮） |
| `更新补丁` | 下载补丁包并升级（URL 在面板「系统设置 → 更新系统配置」配置） |
| `更新全量` | 下载全量包并升级 |
| `检查更新` | 版本对比，有更新提醒 |
| `更新记录` / `更新列表` | 历史更新记录 |
| `删除更新记录 序号` | 删除指定记录 |
| 群内终端更新命令 | 见上文第 3 节 |

## 5. 版本升级流程（推荐顺序）

1. 在面板「系统设置 → 更新系统配置」维护：更新包版本号、补丁包下载地址、全量包下载地址、更新内容。
2. 群内发送「检查更新」确认有新版本。
3. 发送「更新补丁」（或直接发第 3 节终端命令）。
4. 更新完成后机器人自动重启，群内反馈结果。

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 「服务器未启用 PHP exec」 | 面板部署终端手动执行：`cd /var/www/php && unzip -o <zip> && pm2 restart qqbot` |
| 下载失败 | 检查 URL 是否可访问（8091 预览地址需服务在线）；浏览器/curl 验证 |
| 解压失败 | 确认服务器已装 `unzip`（`apt-get install -y unzip`）；检查包完整性 |
| 更新后功能没变化 | `pm2 logs qqbot --lines 50` 查看日志；确认包已解压到 /var/www/php |
| 只更新了 dist 没更新 src | 补丁包同时含 dist 与 src；全量包含完整源码 + 精简生产依赖 |

## 7. 服务端接收端（AI 发布包一键接收部署）

面板「系统设置 → 更新系统配置」下方的 **服务端接收** 区块，把 AI 端发布的更新包一键接收并部署到服务器，与群内「更新系统」插件/升级列表/重启完全串联。仅超级主人可用。

### 界面操作
- **接收补丁包 / 接收全量包**：自动读取云端 `update-config.json` 的下载地址 → 服务器下载 → `unzip -t` 校验 → 覆盖式解压到部署根 → 写更新记录 → `pm2 restart qqbot`
- **上传 zip 接收**：本地选择 zip 文件上传，走同一套流程
- 状态行显示：解压根目录、当前版本、AI 端最新版本与更新内容

### 后端接口
| 接口 | 说明 |
|------|------|
| `GET /api/system/update-receive/info` | 接收端信息（解压根目录/当前版本/AI 端 update-config 最新配置） |
| `POST /api/system/update-receive` | body `{url}` 远程 zip 直链；或 multipart `file` 本地上传。校验→解压→记录→重启 |

### 行为说明
- **解压根目录**：config `update.receive_root`，留空=面板运行目录（服务器部署时通常即 `/var/www/php`）
- **记录串联**：写入 `data/database/更新/记录.json`（类型 `服务端接收-补丁包/全量包`）+ `状态.json` 当前版本，群内「更新记录」「检查更新」立即生效
- **重启**：自动执行 `cd <面板运行目录> && pm2 restart qqbot`；无 pm2 时接口返回提示手动重启
- **云端配置源**：`update-config.json`（AI 端统一维护版本/补丁URL/全量URL/镜像/更新内容），地址可在「更新配置远程地址」配置（可逗号分隔多个，建议同时填 GitHub Pages 与 8091）；留空=默认按序拉取 GitHub Pages（lzyzyzq.github.io/QQgfbot）→ GitHub raw → raw.gitmirror.com → 8091 备用
- **多源下载**：补丁/全量包按 候选源顺序自动切换（GitHub Release 主源 → ghfast/ghproxy 加速镜像 → 8091 备用），主源失败无需手动改地址
- **发布方式**：GitHub push `v*` tag 自动构建 zip 并挂到 Release（`release.yml`）；发版步骤见仓库 README「更新发布流程」
